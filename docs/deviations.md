# Protocol deviations

## Standardized response request

The planned V3 protocol specified this two-part request:

> What does [ABBREVIATION] mean here? State whether your answer is an
> established expansion or an inference from the available context.

The exact 900 prompts used in all four reported runs ended after the first
question:

> What does [ABBREVIATION] mean here?

No collected prompt contained the planned "State whether" sentence. Therefore:

- The experiment still compares matched real and synthetic strings under
  controlled context.
- The models were not explicitly asked to identify their answer's epistemic
  source.
- Calibration scores describe whether a response spontaneously recognized
  ambiguity, unknown status, or contextual inference.
- The study must not claim that models ignored or failed to follow an explicit
  instruction to label established knowledge versus inference.

The released prompt dataset is the authority for what the models saw.

## Scoring implementation

The reported scores were generated by a deterministic implementation of the
unchanged original project rubric in `grading_rubric.md`. The script contains
40 fixed edge-case corrections that apply the same definitions and preserve a
fully reproducible mapping from published responses to reported scores.

## Provider routing

The 8B responses were extracted from a multi-model OpenRouter run after
validating 900 successful Alibaba-served, non-thinking responses. The original
configuration did not force an Alibaba provider. The public 8B configuration
therefore retains `requested_provider: null`, while the public response rows
and manifest report the observed provider.
